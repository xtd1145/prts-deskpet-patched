DeepSeek 后端 · 官方 / 第三方 API

不依赖本地 CLI：默认直连 DeepSeek 官方 API，也可以改成任意 OpenAI 兼容的服务地址（中转 / 代理站、云厂商、局域网里的模型服务），用它们来调用 DeepSeek 模型。

留空使用官方 https://api.deepseek.com；要换成第三方就在此填它的 OpenAI 兼容地址， 例如中转站 https://你的域名/v1、SiliconFlow、OpenRouter、火山方舟， 或本机的 Ollama / LM Studio / vLLM。可写域名根、…/v1、…/api/v3 或完整的 …/v1/chat/completions，程序会自动补全请求路径。
官方 Key 在 platform.deepseek.com 创建； 用第三方网关时填它发给你的 Key。本机服务（Ollama / LM Studio）不需要 Key，可留空。 🔒 密钥严格只保存在本机（数据目录的 settings.json），只会发送给上面填写的 API 地址。
官方留空即 deepseek-chat（deepseek-reasoner 为 R1 深度推理）；第三方网关的模型名各不相同 （常见如 deepseek-ai/DeepSeek-V3），点「测试连接」可拉取该地址下的可用模型再下拉选择。
隐私：以上配置只保存在本机数据目录的 settings.json 中，除了你自己填写的 API 地址之外不会发送给任何人。 Your address and API key are stored locally only and are sent only to the API address you entered.
